| 文件 | 内容 |
| --- | --- |
| `recompute_ledger_and_views.py`、`recompute_output.txt` | 从仓库里的账本导出独立重算：当前账本的毛、净回报率和区间；按修复前、修复后两种逻辑重算业绩视图并与导出的线上视图逐行比对；10-30 快照的三种算法。用法写在脚本开头 |
