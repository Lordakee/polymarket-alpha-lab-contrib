## 设计（全部位于该测试文件内）

1. 新增模块级常量 `_SEED_FAILURE_DIAGNOSTICS`（纯 stdlib 字符串，供 seed 子进程执行）：`_chain(exc)`（BFS≤4，via/suppress/errno 仅 `type(...) is int`）、`_seed_tcp_counts(name, port)`（上述边界语义的独立副本；既有模块函数 `_old_seed_tcp_counts` 不动，二者语义由测试分别钉住，刻意不交叉重构）、`_seed_failure_emit(error, port, stream=None)`（整体包裹 try/except BaseException，自身任何失败不得吞掉/替换原异常；输出单行 `OLD_SEED_FAILURE_MOMENT code=… chain=<json> tcp=… tcp6=…`，端口无效记 `PORT_UNAVAILABLE`）。
2. `_SEED_PAYLOAD`：顶部导入追加 `ProjectDatabaseError`（OLD `project_postgres.files`）；主体包一层 `try: … except (OSError, ProjectDatabaseError) as error: _seed_failure_emit(error, _port); raise`（bare re-raise，异常对象不变）；`_port` 来自新增可选 `sys.argv[2]`（int 且 1..65535，否则 None→不快照）。payload 其余字节与业务逻辑不动。
3. 唯一 harness 调用点 `:928` 追加端口实参：`_old_payload(rig, 'seed.py', _SEED_PAYLOAD, str(original), str(rig['port']))`。`_OLD_RUNNER`/`_OLD_ENTRY`/`_old_payload`/`_observe_old_seed_exit`/`_old_seed_tcp_counts` 及全部断言不动。
4. 输出纪律延续：无地址（原始或编码）、无 inode/PID/其他端口、无凭据/DSN/SQL/locals；仅计数、相对帧、固定 reason code 与类型/errno 标量。

## 离线合成测试（新增；沿用既有 `_synthetic_old_seed_runner`/`_synthetic_seed_proc` 架构）

新增 `_synthetic_seed_payload`：向 `sys.modules` 注入 fake `polymarket_alpha_lab*`（SimpleNamespace/轻类，满足 payload 的 6 组导入与 `db.session()`/`status()` 形状），exec 真实 `_SEED_PAYLOAD`，argv=[payload, root, port]，monkeypatch `builtins.open` 喂合成 `/proc/net/tcp{,6}`；用后清理 sys.modules。用例：
- T1 帧链 from-None 语义：fake session 抛 `OSError(98)`→payload 内层 `raise PDE-like from None` 场景与直接 OSError 场景各一，断言 `code=`、`via=raised`、context 链含 OSError、`suppress_context=true` 可见、帧 `src/...server.py:146:_start` 形状（用带真实 `__traceback__` 的合成异常构造）。
- T2 非整数 errno：`errno` 为 None/True/'98'/98.0 时字段为 null，不抛、不误报。
- T3 proc 边界：>65536 截断、无结尾换行、表头错、坏 state/endpoint、open 异常 → `UNAVAILABLE`；正确输入 → 仅 local/peer 计数且只含任务端口。
- T4 成功路径零输出：fake 全成功 → stderr 无 `OLD_SEED_FAILURE_MOMENT`，stdout 正常 JSON。
- T5 观察失败不吞原异常：monkeypatch `_chain`（exec 命名空间内）抛错 → emit 不向外抛，payload 原异常原样传播、bare-raise 帧计数=1（对齐既有 `frames.count(...) == 1` 风格）。
